# My stuff

My personal app: inventory, wishlist, bucket list, notes and a map of places.

- The app: `index.html` (opens at https://ph4m1k.github.io/my-stuff/)
- My data lives in Supabase behind my login, not in this repository.
- `supabase/functions/import-link` turns a shared TikTok link into pins on the map.
- The Route planner's public transport connections come from [Transitous](https://transitous.org/) ([data sources](https://transitous.org/sources/)), a free community journey planner. This app sends it a few requests only when I press "Plan my route" or "Done here".
- Map data © OpenStreetMap contributors; maps by MapTiler.
